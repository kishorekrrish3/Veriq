ABOUT VERIQ

What is VERIQ and why does it matter?

When developers ask AI coding assistants to write code, the AI generates plausible-looking code and assumes it works. In reality, subtle bugs, wrong imports, syntax errors, and breaking regressions slip in unnoticed. VERIQ is an Evidence-Driven Autonomous Engineering Agent. It writes code, isolates it in a safe sandbox, runs real automated tests, and verifies that the code actually works before touching your project.

How VERIQ works: The 4-step pipeline

From plain English description to proven, mathematically verified code

1

Research & Grounding

VERIQ analyzes your task and uses Tavily AI Search to fetch live, authoritative library docs, parameter specifications, and constraints.

Eliminates hallucinations by grounding code in real documentation.
2

Smart AI Model Selection

VERIQ estimates the task complexity and routes it to the optimal NVIDIA Nemotron model on Nebius: Fast 30B, Balanced 70B, or Expert 340B.

Cuts response time by 54% and token costs by 62%.
3

Safe Sandbox Testing

Before applying any changes to your project, VERIQ runs the new code inside an isolated Docker Container with zero network access and stripped credentials.

100% safe. Cannot contaminate host files or leak API keys.
4

Proof Ledger & Self-Repair

If tests pass, VERIQ logs an honest proof receipt. If tests fail, it automatically reads the terminal error and repairs the code (up to 3 tries) until tests pass.

Zero guessing. You receive verified proof of working code.

How to connect your free Google Cloud OAuth ID
  1. Open Google Cloud Console → Credentials.
  2. Create an OAuth 2.0 Client ID (Web application).
  3. Set Authorized redirect URI: http://127.0.0.1:8000/api/auth/google/callback.
  4. Add to your project .env file: 
    GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-client-secret
