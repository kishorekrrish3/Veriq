# VERIQ — Product & Design Context

## Brand Identity
- **Name**: VERIQ
- **Tagline**: Code is generated. Proof is earned.
- **Mission**: Evidence-driven autonomous engineering agent built for the Nebius × NVIDIA Global AI Hackathon 2026.
- **Primary Proposition**: Every AI engineering claim must be backed by inspectable, deterministic proof (AST parse, import isolation, pytest execution, Tavily documentation grounding, isolated sandbox containers).
- **Core Truth**: Distinguish AI assertions from deterministic facts. Passing syntax checks does not prove functional correctness; passing tests does not prove universal truth.

## Surface Modes
- **Operate (Primary)**: Engineering workbench for configuring runs, live streaming execution telemetry, inspecting unified diffs, running bounded self-repair, and auditing verification ledger claims.
- **Persuade (Overview)**: Executive summary of verification rates, proven runs, and single-model baseline vs. cascade benchmark comparisons.
- **Read (Ledger & Reports)**: Deep inspectability into cryptographic evidence IDs (`EVID-xxx`), command executions, exit codes, stdout/stderr, and explicit system limitations.
